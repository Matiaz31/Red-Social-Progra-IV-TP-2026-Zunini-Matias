# Red Social - Programación IV

## Descripción del proyecto

Desarrollo de una aplicación web de red social como Trabajo Práctico de la materia Programación IV.

La aplicación permite a los usuarios registrarse, iniciar sesión, gestionar su perfil e interactuar con publicaciones de otros usuarios.

El proyecto está desarrollado utilizando una arquitectura frontend y backend, con comunicación mediante una API REST.

## Tecnologías utilizadas

### Frontend
- Angular
- TypeScript
- HTML
- SCSS

### Backend
- NestJS
- Node.js
- TypeScript
- Mongoose

### Base de datos y servicios
- MongoDB Atlas
- Cloudinary (almacenamiento de imágenes)

## Funcionalidades

### Sprint 1
- Registro de usuarios.
- Inicio de sesión.
- Validación de datos.
- Autenticación mediante JWT.
- Gestión de contraseñas con hash.
- Carga de imágenes de perfil.
